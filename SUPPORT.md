# Support

Camenya is a volunteer, best-effort open-source project. There is no paid support, service-level agreement, guaranteed response, compatibility promise, release schedule, or obligation to implement a request.

For a reproducible defect in the official source, use the GitHub bug-report form. For a new idea, use the feature-proposal form after reading `GOVERNANCE.md`. Search existing issues first and keep one problem per issue.

The project cannot troubleshoot third-party binaries, forks, modified signing scripts, Apple Account access, Xcode installation, expired provisioning, damaged development machines, or unrelated Apple services.

Never share Apple credentials, certificates, private keys, provisioning profiles, Team IDs, device identifiers, personal bundle identifiers, raw logs, private recordings, or absolute home paths when asking for help. Maintainers may close reports that cannot be handled safely or that fall outside the project scope.
