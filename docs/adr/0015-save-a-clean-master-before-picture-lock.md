# Save a Clean Master before Picture Lock

Finish Video encodes the checked Primary Storyline without captions or finishing overlays, validates that Clean Master, and saves it to Photos before committing Picture Lock. Camenya durably records validation and the start of the Photos transaction. A confirmed Photos failure clears only that in-flight marker and remains exactly retryable; confirmed success is recorded before Picture Lock. If the process stops or storage fails after Photos may have committed but before local confirmation, Camenya never repeats the save automatically: it preserves the master and asks the user to check Photos, then explicitly confirm the asset or choose **Save Again**. The shipping Picture Lock transition accepts only that exact, current, Photos-confirmed checkpoint.

This gives the user an early, independently usable clean result before spending time on captions and overlays, while final Project Export remains the only output containing finishing presentation. The Clean Master is a replaceable recovery and production checkpoint; immutable Takes and the locked Storyline remain the canonical sources for every later export.

This narrows ADR 0004: Take finalization still never saves to Photos, but explicit Finish Video is now an additional Photos boundary before final Project Export. It extends ADR 0012: Picture Lock is created by Finish Video after the Clean Master transaction, while Caption Track creation remains a separate post-lock action.

Projects locked by schema 10 predate this checkpoint. Migration preserves their immutable Picture Lock and any completed Caption Track, but withholds captions, Text Overlays, and final export until the user explicitly runs **Finish Video**. That operation renders the same presentation-free locked sources, validates and saves the Clean Master, then attaches the Photos-confirmed checkpoint to the existing lock without discarding its captions. Migration never invents a Photos confirmation and never destroys finished work.
