# Product

## Register

product

## Users

Camenya serves one person recording direct-to-camera projects on an iPhone. The user is usually holding the device, watching framing, recalling a script, and needs to capture, review, reorder, and discard multiple Takes while retaining the ability to alternate between front and rear cameras inside each Take.

## Product Purpose

Camenya keeps multiple ephemeral recording Projects locally on one device. Within each Project, the user can create reliable Takes from multiple camera Segments, review and reorder them on one Timeline, discard failed attempts, and explicitly export exactly one correct movie to Photos when ready.

## Brand Personality

Calm, tactile, trustworthy. Camenya should feel focused and native, with the confidence of a dedicated physical recording tool and none of the noise of a creator platform.

## Anti-references

- A professional camera control deck packed with exposure, lens, waveform, and codec controls.
- A social-video creator interface filled with filters, stickers, feeds, trends, and promotional prompts.
- A decorative glass dashboard whose effects compete with the live preview.

## Design Principles

1. Keep the active task primary: the preview while capturing, and the selected Take while reviewing. Controls must remain legible without obscuring the subject.
2. Make the next valid action obvious. Record, Pause, Resume, Flip, and Stop must never compete equally.
3. Show recording truth plainly. Camera position, elapsed time, paused state, and transitional work must be unmistakable.
4. Earn every control. If it does not support Project selection, the core Take workflow, Timeline review, or Project Export, it does not belong.
5. Protect confidence. Destructive actions, interruptions, recovery, and saving must explain what is safe.

## Accessibility & Inclusion

Use native Dynamic Type, VoiceOver labels and hints, minimum 44-point targets, strong contrast over arbitrary preview imagery, and semantic state that does not rely on color alone. Motion is limited to short state feedback and respects Reduce Motion through native system behavior.
